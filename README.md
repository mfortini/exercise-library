# Exercise Library

1,112 exercises with animated GIFs, muscle targeting data, and step-by-step instructions.

## Usage

- exercises.json — All exercise data
- gifs/ — Animated GIF demonstrations

## Data Format

`json
{
  "id": "string",
  "name": "string",
  "gif": "filename.gif",
  "targetMuscles": ["string"],
  "secondaryMuscles": ["string"],
  "bodyParts": ["string"],
  "equipment": ["string"],
  "instructions": ["string"]
}
`

## GIF URL Pattern

`
https://raw.githubusercontent.com/USERNAME/exercise-library/main/gifs/{gif}
`

## Coverage

- 1,112 exercises with animated GIFs
- 19 muscle groups
- 25+ equipment types
- Full instructions for each exercise
